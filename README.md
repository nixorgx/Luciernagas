# Luciérnagas — Luz para su mañana

Sitio informativo de una iniciativa social en formación en Bolivia. Nuestro propósito es facilitar oportunidades educativas para niñas y niños mediante la solidaridad de la comunidad.

## Qué encontrarás

- Nuestra misión y los programas de donación de libros/material escolar, tutorías y talleres extracurriculares.
- Un formulario de colaboración en tres pasos para comunicar propuestas.
- Preguntas frecuentes y un mecanismo para compartir la iniciativa.
- Diseño adaptable, navegación fija y un fondo discreto de luciérnagas animadas, con soporte para movimiento reducido.

## Publicación

El sitio está publicado en GitHub Pages desde la rama \`main\`:
https://nixorgx.github.io/Luciernagas/

Es una aplicación web estática, elaborada con HTML, CSS y JavaScript sin dependencias de instalación.

El formulario utiliza una conexión protegida a Supabase para registrar propuestas. Nunca procesamos donaciones monetarias en el sitio. No compartas información personal de niñas o niños mediante el formulario.

## Identidad visual y fotografías

Colores principales: verde bosque, crema y ámbar. Las imágenes documentales de Bolivia se muestran a través de Wikimedia Commons y sus licencias y autores se detallan en la sección «Créditos de las fotografías» del sitio.

Este proyecto se encuentra en una etapa de formación. No se anuncian actividades, fechas ni canales de donación de dinero que no estén confirmados.
